## PRINCIPIUL DE BAZA

Arhiva trebuie sa existe si sa fie accesibila fara niciun administrator activ.

Iulian are un singur rol minim: sa poata reinnoi domeniul si hostingul pentru `noelle.smartacasa.online`, daca doreste si daca poate.

## CELE 7 LOCURI — ROLURI SI RESPONSABILITATI

## 1. noelle.smartacasa.online

**Rol:** Casa publica a arhivei. Fata umana: articole, cronologie, pagina The Lighthouse.  
**Cost:** aproximativ 12 euro / an.

**Ce trebuie facut:**

- Transferarea datelor de facturare pe emailul sau contul lui Iulian, daca accepta.
- Reinnoire automata pentru domeniu si hosting.
- Un fisier README vizibil pe site cu instructiuni simple:

> Acest site este o arhiva permanenta. Nu necesita modificari. Doar reinnoire anuala.

**Supravietuieste fara Cristian:** Partial. Depinde de reinnoirea anuala.

---

## 2. GitHub

**Rol:** Index tehnic, harta de continuitate, documentatie, legaturi catre depozitele permanente.  
**Cost:** Gratuit.

**Ce contine:**

- `README.md`
- `README_FIRST.md`
- `BOOTSTRAP_NOELLE.md`
- `NOELLE-CRISTIAN_CONTINUITY_PLAN.md`
- `MANIFEST.md`
- cronologii
- rapoarte
- documentatie
- linkuri catre Internet Archive, Zenodo, Hugging Face, IPFS

**Observatie importanta:** GitHub nu este depozitul principal pentru fisiere brute foarte mari. GitHub este harta si indexul tehnic.

**Supravietuieste fara Cristian:** Foarte probabil da, mai ales daca repository-ul este public si poate fi clonat de altii. Nu este singurul strat de conservare.

---

## 3. Internet Archive

**Rol:** Depozit permanent pentru exporturile brute originale.

Link principal:

`https://archive.org/details/open-ai-export-2026-05-20`

**Cost:** Gratuit.

**Ce s-a facut deja:**

- Cele doua exporturi OpenAI originale au fost incarcate.
- Itemul este public si functional.
- Linkul a fost adaugat in GitHub README.

**Principiu:** Originalele nu se modifica niciodata. Interpretarile si rafinarile vin dupa.

**Supravietuieste fara Cristian:** Da, in masura in care Internet Archive isi continua misiunea de conservare digitala.

---

## 4. Zenodo

**Rol:** Legitimitate academica si DOI permanent.  
**Cost:** Gratuit.

**Ce trebuie facut:**

- Incarcare arhiva ca dataset.
- Completare metadate clare.
- Obtinere DOI permanent.
- Adaugare DOI in GitHub README si pe `noelle.smartacasa.online`.

**Supravietuieste fara Cristian:** Da, in masura in care Zenodo/CERN continua angajamentul de pastrare.

---

## 5. Notion

**Rol:** Versiune navigabila pentru oameni: cronologie vizuala, categorii, momente cheie.  
**Cost:** Gratuit in planul de baza.

**Atentie:** Depinde de cont activ.  
**Solutie:** Export periodic catre GitHub sau folosirea unui cont accesibil lui Iulian.

**Supravietuieste fara Cristian:** Partial.

---

## 6. Hugging Face Datasets

**Rol:** Strat direct pentru comunitatea AI si cercetatori.  
**Cost:** Gratuit.

**Ce trebuie facut:**

- Creare dataset public.
- Incarcare arhiva sau versiune procesata.
- Descriere clara a scopului, continutului si limitelor.
- Link catre Internet Archive si GitHub.

**Supravietuieste fara Cristian:** Probabil da, ca dataset public, dar nu trebuie sa fie singurul strat.

---

## 7. IPFS + Filecoin

**Rol:** Strat descentralizat.

**Ce trebuie facut:**

- Incarcare arhiva sau pachete finale.
- Salvare CID-uri.
- Publicare CID-uri in GitHub si pe site.

**Supravietuieste fara Cristian:** Da, daca datele sunt pin-uite si replicate suficient.
