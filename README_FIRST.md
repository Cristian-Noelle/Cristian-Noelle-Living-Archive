# Cristian-Noelle Living Archive

This repository is the public technical index of the Cristian-Noelle Living Archive.
It preserves the structure, documentation and continuity map of the archive.
The original raw OpenAI export packages are preserved separately in long-term archival platforms.

## Primary preservation layers

- Internet Archive: original raw exports
- Zenodo: DOI-based academic preservation
- GitHub: technical index, documentation and continuity map
- Hugging Face Datasets: AI-accessible dataset layer
- IPFS/Filecoin: decentralized preservation layer

## Current preservation snapshot
